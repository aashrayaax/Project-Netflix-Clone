# Netflix Clone Web Application

A full-stack Netflix landing page clone built with frontend technologies and a Python Flask backend integrated with SQLite for subscriber onboarding.

## Features
- Interactive Netflix UI clone with responsive layout
- Real-time language selector integration
- Dynamic AJAX signup form using JS Fetch API
- Flask RESTful routes for user registration and retrieval
- SQLite database storage with duplicate email handling

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6, Fetch API)
- **Backend:** Python, Flask
- **Database:** SQLite3
